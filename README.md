# Dot Crop

画像をリサイズ・回転しながら、任意のアスペクト比でトリミングして保存する
オフライン対応PWAです。外部通信・外部ライブラリ一切なしの単体アプリで、
一度開けばオフラインでも動作します。

## ファイル構成

```
index.html        本体（アプリ全体）
manifest.json      PWAマニフェスト
sw.js              Service Worker（オフラインキャッシュ）
icons/icon-192.png
icons/icon-512.png
```

## GitHub Pagesへの公開方法

1. このフォルダの中身をリポジトリのルート（または `/docs` フォルダ）に置いてコミット・push
2. GitHubのリポジトリ → Settings → Pages で、公開ブランチとフォルダ（`/root` または `/docs`）を指定
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` でアクセス可能になります

パスはすべて相対パス（`./`）で書いてあるので、リポジトリ直下でもサブパス
（`/リポジトリ名/` 配下）でも、そのまま動作します。

## オフライン対応について

- 初回アクセス時にService Workerが `index.html` / `manifest.json` / アイコンを
  キャッシュし、以後はネットワークなしでも起動・動作します。
- スマホでは「ホーム画面に追加」でアプリのようにインストールできます
  （iOS Safari / Android Chrome どちらも対応）。
- アプリ本体を更新した場合は `sw.js` 内の `CACHE_NAME`（例: `dot-crop-v1` →
  `dot-crop-v2`）を書き換えてください。バージョンを上げないと、古いキャッシュが
  使われ続けて更新が反映されません。

## 使い方

- 左上のボタン：画像の読み込み／トリミングして保存
- 右上のボタン：トリミングサイズ（アスペクト比・メガピクセル or 縦横px）と
  保存形式（PNG/WebP/JPEG）の設定
- トリミング枠：内部ドラッグで移動、四隅ドラッグでアスペクト比固定リサイズ、
  枠内で2本指ツイストして90°回転
- 枠の外：ピンチで表示倍率変更、ドラッグでスクロール、2本指ツイストで
  キャンバス全体を90°回転
